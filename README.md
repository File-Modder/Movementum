# *MOVEMENTUM*

*--- what is Movementum? ---*
\
Movementum is a versitile Mincraft mod that aims to improve the slow feeling of combat by introducing new movement options and new enchantments! (Visit the [wiki](https://github.com/File-Modder/Movementum/wiki) for more information).
